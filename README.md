# Sailfish 2

Rust で書かれた USI プロトコル対応の将棋エンジンです。[Sailfish 1.0](https://github.com/goro0803-droid/sailfish) から分かれた、より強いバージョンです。
[将棋アリーナ (Shogi Arena)](https://github.com/goro0803-droid/shogi-arena) に同梱されています。ほかの USI 対応 GUI にも登録して使えます。

評価関数は、手作りの評価関数に、**自分の自己対戦から学習したニューラルネットワーク**の補正を足したものです。
外部の評価関数ファイルは要りません（ネットワークは実行ファイルに埋め込まれています）。

## Sailfish 1.0 との違い

| | 1.0 | 2.1 |
|---|---|---|
| 探索スレッド | 1 | **複数**（Lazy SMP。置換表を全スレッドで共有） |
| 静止探索の置換表 | なし | **あり** |
| 評価関数 | 手作り | 手作り + **ニューラルネットワークによる補正** |

### 強さの目安
水匠5 を 2,000 ノードに制限した相手との 100 局（1 手 150ms、1 スレッド）の勝率です。

| エンジン | 勝率 |
|---|---|
| Sailfish 1.0 | 15.5% |
| Sailfish 2.0（ネットワークなし） | 15.0% |
| **Sailfish 2.1** | **42.0%** |

自己対戦（1 手 150ms、1 スレッド）では、ネットワークなしの同じエンジンに 100 局で 92勝8敗（勝率 92%）でした。
自己対戦の差は、別の相手との差より大きく出ます。水匠5 のような大規模な評価関数には、まだ及びません。

## ニューラルネットワークについて
- 入力は、駒の種類×持ち主×升、持ち駒の個数、玉の周り（±3 升）の駒の相対位置です。駒が動くたびに差分だけ更新します（NNUE と同じ考え方）。
- 手作りの評価関数を土台にして、ネットワークは「その補正」だけを学びます。
- 学習データは、**Sailfish 自身の自己対戦だけ**です（他のエンジンの出力や、他人の棋譜は使っていません）。
  前の世代のネットワークで指した棋譜から、次の世代を学習する、という繰り返しで強くしています。
- 学習ツールは `src/bin/nn_train.rs`、棋譜を作るツールは `tools/datagen.mjs` です。

## ビルド

```
cargo build --release
```

実行ファイルは `target\release\sailfish2.exe` にできます。

## エンジンオプション

| 名前 | 既定値 | 説明 |
|---|---|---|
| USI_Hash | 256 | 置換表のサイズ (MB) |
| NetworkDelay | 120 | 時間切れを防ぐため、思考時間から差し引く余裕 (ms) |
| MultiPV | 1 | 候補手をいくつ読むか (1〜10) |
| Threads | CPU に合わせて自動（論理コア数の半分、最大 4） | 探索スレッドの数 (1〜64) |
| UseNeuralNet | true | ニューラルネットワークの補正を使うか（false なら手作りの評価関数だけ） |

## 構成

| ファイル | 内容 |
|---|---|
| `src/types.rs` | 駒・指し手の表現、方向テーブル、Zobrist ハッシュ |
| `src/position.rs` | 局面、SFEN 読み込み、指し手生成、合法性判定、SEE（駒の取り合いの損得） |
| `src/eval.rs` | 手作りの評価関数（駒割り、玉の危険度、大駒の働き、攻め駒・守り駒の位置、取られそうな駒） |
| `src/nn.rs` | ニューラルネットワーク（特徴、差分更新、順伝播、ファイルの読み書き） |
| `src/search.rs` | 反復深化 PVS、静止探索、置換表、ヌルムーブ、LMR、枝刈り、キラー／ヒストリー／カウンター手、MultiPV、複数スレッド、時間管理 |
| `src/tt.rs` | 複数スレッドから同時に読み書きできる置換表 |
| `src/main.rs` | USI プロトコル処理（ponder / infinite / stop 対応） |
| `nets/default.nn` | 実行ファイルに埋め込む標準のネットワーク |
| `src/bin/nn_train.rs` | ネットワークの学習ツール |
| `src/bin/tune.rs` | 駒の位置の点数表の学習ツール（試作。効果がなく、使っていません） |
| `tools/match.mjs` | エンジン同士の自動対局でレート差を測るツール |
| `tools/datagen.mjs` | 学習用の自己対戦の棋譜を作るツール |
| `tools/bench.mjs` | 速度の計測 |
| `tools/usi-test.mjs` | GUI が行う USI の操作（読み続けて停止、MultiPV、ponder など）の動作確認 |

`tools/match.mjs` と `tools/datagen.mjs` は、指し手の判定に隣のフォルダにある将棋アリーナのルール実装（`../ShogiArena/src/js/shogi.js`）を使います。

## デバッグ用コマンド

エンジンを直接起動して入力できます。

- `d` 盤面表示
- `moves` 合法手一覧
- `eval` 静的評価値（手作りの評価関数のみ）
- `evalbench [回数]` 評価の速さの計測
- `perft N` 深さ N までの合法手ノード数
