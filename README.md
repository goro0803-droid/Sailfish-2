# Sailfish 2

Rust で書かれた USI プロトコル対応の将棋エンジンです。[Sailfish 1.0](https://github.com/goro0803-droid/sailfish) から分かれた、より強いバージョンです。
[将棋アリーナ (Shogi Arena)](https://github.com/goro0803-droid/shogi-arena) に同梱されています。ほかの USI 対応 GUI にも登録して使えます。

評価関数は、手作りの評価関数に、**強いソフトの評価（めきっと氏の公開教師データ）から学習したニューラルネットワーク**の補正を足したものです（2.1 までは自分の自己対戦から学習）。
外部の評価関数ファイルは要りません（ネットワークは実行ファイルに埋め込まれています）。

## 2026-10-08 Sailfish 2.3

現在の標準は **Sailfish 2.3**。探索・時間配分・ネットワークの形（入力 → 64 → 32 → 1）は 2.2 と同じで、評価関数のネットワークを、めきっと氏の公開教師データの**全体**（1億8,187万局面から選んだ静かな局面 約9,900万）でゼロから学習したもの（B2-64）に替えました。2.2 の学習データの約16倍です。
2.2 との対局で、1手1秒 600局 407勝175敗18分（69.3%、約 +142 Elo）、5分＋10秒 40局 27勝12敗1分（68.8%）。
大きなデータを扱うため、学習ツールを「全局面をメモリに載せず、少しずつ読む」作りに替えました（`psv_prepare` と `nn_train --psv`）。

## 2026-10-06 Sailfish 2.2

この時点の標準は **Sailfish 2.2**。探索と時間配分は 2.1 Codex Delta Time と同じで、評価関数のネットワークを、めきっと氏の公開教師データ（強いソフトが深さ12〜14で付けた評価）約600万局面でゼロから学習したもの（A2）に替えました。ネットワークの形（入力 → 64 → 32 → 1）は変えていません。
2.1（第5世代ネット R5）との対局で、1手1秒 600局 518勝78敗4分（86.7%）、5分＋10秒 40局 36勝4敗（90.0%）。詳しくは [実験Aのレポート](REPORT_実験A_めきっとデータ_20261006.md)。

## 2026-10-03 ローカル強化版

この時点の標準は **Sailfish 2.1 Codex Delta Time**。序盤の時間を抑え、中盤へ残す配分を追加しました。加算対局の初期5分＋10秒では、最初の10手の目標は1手約7.9秒、上限約11.9秒です（残り時間に応じて変化）。[時間配分の変更と検証](REPORT_時間配分改善_20261003.md)を参照してください。5分＋毎手10秒の初期20局比較は13勝5敗2分（得点率70%）。序盤の消費中央値は約80秒対旧版約244秒。ただし20局では棋力差の確定には少ない。[負けた5局の原因調査](REPORT_Time版5敗の原因調査_20261004.md)も保存しました。時間切れ0、重要局面の長時間再分析と枝刈り診断を実施し、明確な敗着は未確定です。

Deltaの探索修正として、駒を取る際の「持ち駒になる価値」を、静止探索で手を省略する判断へ反映しました。成りの利得も実際の駒価値の差で数えます。R5ネットは維持しています。

旧標準との600局（1手50ms、1スレッド）で321勝271敗8分、得点率54.2%、先後ペアの95%目安50.1〜58.2%。この条件で改善を確認できた修正だけを採用しました。王手を広げる案とSEE全体の変更は不採用。1手500msでの追加600局は296勝273敗31分、51.9%（95%目安48.0〜55.8%）で改善は未確定。水匠戦の再確認は未実施です。

18件のテスト、最終候補との探索一致、USI動作確認に成功。通常実行ファイルと隣のShogiArenaの同梱実行ファイル2か所を更新し、旧版をbaselineへ保存済みです。アプリを開き直すと新しいエンジンを読み込みます。[図入りの検証記録と戻し方](REPORT_戦術探索と駒交換_20261003.md) を参照してください。

公開教師（めきっと氏作）を使った小規模追加学習も検証しました。標準Deltaとの追加600局150msは304勝289敗7分、51.25%（95%目安47.28〜55.22%）。改善を確定できず、標準ネットへの採用を見送りました。教師入力の拡張後は19件のテスト成功。[公開教師の学習・対局記録](REPORT_公開教師小規模学習_20261003.md)を参照してください。

## 2026-10-04 逃げ・守りの手の探索保護

攻撃され守りのない駒の安全な逃げと、大駒の守りを保護する機能を実装。LMRだけ緩める案と浅い手の省略も抑える案を比較し、初期は58.5%/51.5%。最良案の追加400局100msは193勝197敗10分（49.5%）で改善未確定、標準不採用。31テスト、無効時の探索一致、USI4スレッド確認に成功。ソース・候補は既定OFFで保存し、標準TimeとR5は維持。[逃げと守りの探索保護の検証記録](REPORT_逃げと守りの探索保護_20261004.md)を参照してください。

## 2026-10-04 特異延長の実装・検証

有力な手を外した確認で他の手が評価基準に届かない場合、その手を1手分深く読む特異延長を実装しました。初期100局は50勝50敗、別seedの追加400局100msは212勝181敗7分（53.875%、先後ペア95%48.998〜58.752%）。勝ち越しましたが改善は未確定で標準採用は保留、既定OFFの実験機能としてソースと候補を保存しています。27件のテスト、無効時の旧版との探索一致、USI4スレッド動作確認に成功。標準TimeとR5は維持。[特異延長の仕組みと検証結果](REPORT_特異延長の実装と検証_20261004.md)を参照してください。

## 2026-10-04 危険な応手の探索実験

応手の組み合わせ履歴・省略の抑制・読み直しの調整を実装し、初期各100局と追加400局を比較。最良候補の追加確認は192勝197敗11分（49.375%）で改善未確定、標準への採用を見送りました。駒交換の損得再利用も同一実行ファイルでの速度改善を確認できず不採用。標準TimeとR5は維持し、対局ツールに各手の評価値・読み筋の保存を追加しました。[実験の結果と保存した候補](REPORT_危険な応手の探索実験_20261004.md)を参照してください。

## 2026-10-02 ローカル強化版（前回の記録）

この時点の標準は Sailfish 2.1 Codex。標準ネットを第5世代へ更新し、AVX計算と土台評価の再利用で、6局面の反復ベンチマークの探索速度が9.9%向上しました。測定中の指し手・評価値・ノード数は従来版と一致しています。

短い探索の評価が不安定な局面を選び、Sailfish自身の深い探索で再ラベルする `nn_relabel` を追加しました。水匠5（2,000ノード制限）との600局は標準46.4%、独自学習候補49.3%。差はまだ統計的に確定せず、候補は実験用として保存しています。50%超の目標は未達です。

初回強化のテスト10件とUSI動作確認を通過。floodgateの取り込み・重複除去の追加後は合計13件のテストが成功しています。公開・pushは行っていません。詳細と再現手順は [強化記録](REPORT_Codex_20261002.md) を参照してください。以下の2.1の対局表は過去の公開版の結果です。

floodgate棋譜を使用した初回学習では、教師70%候補が水匠5（2,000ノード）に600局で45.4%、教師90%候補が41.7%でした。棋力の改善を確認できず、標準への採用を見送りました。ツール・教師データ・実験モデルは保存済みです。[floodgate実験記録](REPORT_Floodgate_20261002.md) に条件と結果を記載しています。

## Sailfish 1.0 との違い

| | 1.0 | 2.1 |
|---|---|---|
| 探索スレッド | 1 | **複数**（Lazy SMP。置換表を全スレッドで共有） |
| 静止探索の置換表 | なし | **あり** |
| 評価関数 | 手作り | 手作り + **ニューラルネットワークによる補正** |

### 強さの目安
水匠5 を 2,000 ノードに制限した相手との 100 局（1 手 150ms、1 スレッド）の勝率です。

| エンジン | 勝率 |
|---|---|
| Sailfish 1.0 | 15.5% |
| Sailfish 2.0（ネットワークなし） | 15.0% |
| **Sailfish 2.1** | **42.0%** |

自己対戦（1 手 150ms、1 スレッド）では、ネットワークなしの同じエンジンに 100 局で 92勝8敗（勝率 92%）でした。
自己対戦の差は、別の相手との差より大きく出ます。水匠5 のような大規模な評価関数には、まだ及びません。

## ニューラルネットワークについて
- 入力は、駒の種類×持ち主×升、持ち駒の個数、玉の周り（±3 升）の駒の相対位置です。駒が動くたびに差分だけ更新します（NNUE と同じ考え方）。
- 手作りの評価関数を土台にして、ネットワークは「その補正」だけを学びます。
- 学習データはSailfish自身の自己対戦を基本とします。2026-10-02にユーザーの許可を受け、東京大学floodgateの公開棋譜を例外として利用する実験を追加しました。教師の評価値はSailfish自身の探索で作ります。
  前の世代のネットワークで指した棋譜から、次の世代を学習する、という繰り返しで強くしています。
- 学習ツールは `src/bin/nn_train.rs`、棋譜を作るツールは `tools/datagen.mjs` です。

## ビルド

```
cargo build --release
```

実行ファイルは `target\release\sailfish2.exe` にできます。

## エンジンオプション

| 名前 | 既定値 | 説明 |
|---|---|---|
| USI_Hash | 256 | 置換表のサイズ (MB) |
| NetworkDelay | 120 | 時間切れを防ぐため、思考時間から差し引く余裕 (ms) |
| MultiPV | 1 | 候補手をいくつ読むか (1〜10) |
| Threads | CPU に合わせて自動（論理コア数の半分、最大 4） | 探索スレッドの数 (1〜64) |
| UseNeuralNet | true | ニューラルネットワークの補正を使うか（false なら手作りの評価関数だけ） |

## 構成

| ファイル | 内容 |
|---|---|
| `src/types.rs` | 駒・指し手の表現、方向テーブル、Zobrist ハッシュ |
| `src/position.rs` | 局面、SFEN 読み込み、指し手生成、合法性判定、SEE（駒の取り合いの損得） |
| `src/eval.rs` | 手作りの評価関数（駒割り、玉の危険度、大駒の働き、攻め駒・守り駒の位置、取られそうな駒） |
| `src/nn.rs` | ニューラルネットワーク（特徴、差分更新、順伝播、ファイルの読み書き） |
| `src/search.rs` | 反復深化 PVS、静止探索、置換表、ヌルムーブ、LMR、枝刈り、キラー／ヒストリー／カウンター手、MultiPV、複数スレッド、時間管理 |
| `src/tt.rs` | 複数スレッドから同時に読み書きできる置換表 |
| `src/main.rs` | USI プロトコル処理（ponder / infinite / stop 対応） |
| `nets/default.nn` | 実行ファイルに埋め込む標準のネットワーク |
| `src/bin/nn_train.rs` | ネットワークの学習ツール |
| `src/bin/nn_relabel.rs` | 棋譜局面を選んでSailfish自身の深い探索で教師値を更新 |
| `src/bin/floodgate_import.rs` | 許可されたfloodgate CSA棋譜の選別・変換（外部評価値は除外） |
| `src/bin/tune.rs` | 駒の位置の点数表の学習ツール（試作。効果がなく、使っていません） |
| `tools/match.mjs` | エンジン同士の自動対局でレート差を測るツール |
| `tools/datagen.mjs` | 学習用の自己対戦の棋譜を作るツール |
| `tools/bench.mjs` | 速度の計測 |
| `tools/usi-test.mjs` | GUI が行う USI の操作（読み続けて停止、MultiPV、ponder など）の動作確認 |

`tools/match.mjs` と `tools/datagen.mjs` は、指し手の判定に隣のフォルダにある将棋アリーナのルール実装（`../ShogiArena/src/js/shogi.js`）を使います。

## デバッグ用コマンド

エンジンを直接起動して入力できます。

- `d` 盤面表示
- `moves` 合法手一覧
- `eval` 静的評価値（手作りの評価関数のみ）
- `evalbench [回数]` 評価の速さの計測
- `perft N` 深さ N までの合法手ノード数
